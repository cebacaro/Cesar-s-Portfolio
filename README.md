# cesarbacaro.com

Cesar Bacaro's digital headquarters — founder of [Giigs](https://giigsapp.com/), New Orleans percussionist, software builder, photographer.

Built with Next.js 14 (App Router), Tailwind CSS, framer-motion + lenis.

## Run it

```bash
npm install
npm run dev      # local dev at http://localhost:3000
npm run build    # production build
```

## Editing content

All copy lives in `content/*.ts` — no component edits needed to change text:

| File | Page |
| --- | --- |
| `content/home.ts` | Homepage |
| `content/giigs.ts` | Giigs case study |
| `content/music.ts` | Music |
| `content/photos.ts` | Photography gallery |
| `content/builds.ts` | Builds / projects |
| `content/about.ts` | About |
| `content/now.ts` | Now |
| `content/contact.ts` | Contact intents |
| `content/site.ts` | Name, email, socials, nav, accent colors |

### Updating the Now page (monthly)

Edit `content/now.ts`: change `updated` to the current month, rewrite the
`items`, commit, push. The homepage preview updates automatically from the
same file.

### Placeholders

Anything wrapped in `[PLACEHOLDER: …]` is a spot waiting for real facts
(metrics, testimonials, press, social URLs). Find them all with:

```bash
grep -rn "PLACEHOLDER" content/
```

## Images

Originals live in `public/PHOTOS`, `public/GIIGS`, `public/images`. Pages
only reference optimized derivatives in `public/opt/`, generated by:

```bash
node scripts/optimize-images.mjs
```

To add a photo: drop the original in `public/`, add it to the manifest in
`scripts/optimize-images.mjs`, run the script, then reference `/opt/<name>.webp`
in the relevant content file (with alt text).
